# Catalog batches

One folder every 10 designs: `contact-sheet.png` (sample photo, drawn preview, title, sizes, weights) and
`patterns/<id>.txt`, each design's printed pattern at its smallest and largest size. Redraw with
`scripts/catalog/sheet.sh <batch> <id>...`.
