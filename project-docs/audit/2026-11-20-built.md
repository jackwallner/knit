# What build 30 carries from the 2026-11-20 approved changes

All 15 items in [2026-11-20-approved-changes.md](2026-11-20-approved-changes.md) are in build 30. Item 8 (site and listing copy) shipped separately as 7aea21f. One line per item on what was built and where.

## Defects

1. **Chart fit before purchase.** `DesignView` runs the fit check for everyone and shows which number to change, before any purchase button.
2. **Stash.** A new yarn with any field filled in is kept and named from its fiber or weight; swipe to delete asks first; an untouched new needle is dropped when its sheet closes.
3. **Round within the section** on every guided step, and Go to Round works across the whole section.
4. **Whole Pattern** in the project menu (`WholePatternView`), with the current step marked. A paid design keeps its preview limit before purchase.
5. **Round Raccoon Beanie.** Cast-on loops are drawn in the first row's yarn (drawing code, so every design); the ear step says how to line the ears up with the face; the eyes are a chart with `"stitch": "duplicate"`, sewn on in finishing steps; the design page lists techniques. Record revision 1.
6. **Launch screen** in the paper color (`LaunchPaper`), light and dark.
7. **Largest text and Reduce Motion.** The guided instruction and count wrap, the fabric shrinks first; onboarding fades with Reduce Motion on.
8. **Site and listing copy.** 7aea21f.

## Formerly "first update"

9. **Backup.** `Backup.swift`: one `.ravelbackup` file with projects, counts, frozen plans, PDFs, markers, second counter, notes and stash. Restoring only adds what it does not find, so it cannot set a count back. A failed save is shown (`SaveWatch`).
10. **PDF reader.** Zoom and position are kept per project (`SchemaV3`), the band can step with the count, PDFs open from other apps, and the empty Projects screen has Import Pattern.
11. **Finish screen.** Add a Photo, Share, Knit Again. A finished project no longer blocks Cast On.
12. **Guided screen.** The next instruction under the current one, tappable terms, no overlapping text on change, a steady picture and section label, the size in the title, readable needle sizes.
13. **Project list.** "row 18" or section and round, sorted by last worked, finished date shown. A plain counter's Set Row says "Rows completed".
14. **Search.** `LibrarySearch` (`Shared/Services/Search.swift`): shelf tags, mapped words, garment before size, ages to child sizes, nothing for dog or crochet.
15. **Lock Screen counter.** A Live Activity in the new `RavelWidgets` target. `CountRowIntent` is a `LiveActivityIntent`, so it runs in the app and counts through `knit` and `unknit` on the app's own container. A failed save ends the activity with a message.

Small items: the onboarding button no longer fades on each page, the trial price line no longer overlaps the outgoing page, the Raccoon Beanie is last in Free when it leads Trending, the heading over the yarn weight chips reads "Yarn and Gauge", and the design page says where to measure the head.

## Not done

The 45 non-English store descriptions still name two free designs, not three. Nothing was uploaded to App Store Connect.
