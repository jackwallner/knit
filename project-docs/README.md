# Project docs

Docs that are not part of the published site (`docs/` is GitHub Pages).

- `aso/`: App Store search and listing work.
- `audit/`: the 2026-11-13 pre-release audit and its findings ledger.
- `topical/`: topical designs loop. `plan.md` is the original plan, `drafts/` holds unpublished design records, `previews/` their rendered checks. The runbook is `.claude/rules/topical-loop.md`.
- `asc-screenshots/`: App Store screenshot tooling and localized set provenance.
- `release/`: release-day steps and files staged for launch, such as the Trending list.
- `sample-photos/`: the design pages' knitted sample photos. `style.txt` and `subjects.json` are the prompts (styled after real finished-object phone posts), generated with Codex's built-in image tool into `raw/` (not committed); `scripts/sample-photos.sh` turns them into the asset catalog.
